DSA Roadmap Tracker is a React-based web application designed to help students track their progress through a structured 30-day Data Structures and Algorithms learning plan. The application presents a spreadsheet-style interface where users can mark completed problems, filter tasks by week or completion status, and monitor their overall progress through a dynamic progress bar and detailed statistics.

The application uses Local Storage to automatically save user progress, ensuring that completed tasks remain preserved even after refreshing or closing the browser. Built with React Hooks, the project demonstrates state management, data persistence, filtering functionality, and responsive UI design while providing an organized way for learners to stay consistent with their DSA preparation journey.
